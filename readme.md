# Тренажер терминов по обществознанию (v7.0)

Telegram-бот (`bot.py`) и веб-аналитика (`dashboard.py`) для подготовки к ЕГЭ и ОГЭ по обществознанию.

---

## Быстрый запуск

Установка зависимостей:

```bash
pip install -r requirements.txt
```

Запуск бота:

```bash
python bot.py
```

Запуск дашборда аналитики:

```bash
streamlit run dashboard.py
```

---

## Настройка окружения (.env)

Создайте файл `.env` в корне проекта (или добавьте переменные в настройках Render / Streamlit Cloud):

```ini
BOT_TOKEN=ваш_токен_от_BotFather
DATABASE_URL=postgresql://user:pass@ep-name-pooler.region.aws.neon.tech/dbname?sslmode=require
DASHBOARD_URL=https://ваш-дашборд.streamlit.app
SECRET_KEY=obshaga_secret_key_2025
ADMIN_PASSWORD=ваш_пароль_админа
LOG_CHAT_ID=-1001234567890
TIMEZONE=Europe/Moscow
PORT=10000
```

* `BOT_TOKEN` — обязательный токен бота.
* `DATABASE_URL` — строка подключения Neon PostgreSQL (если не указана, бот автоматически создаст локальную базу `social_bot.db`).
* `DASHBOARD_URL` — HTTPS-ссылка на Streamlit для открытия аналитики прямо внутри Telegram (Mini App).
* `LOG_CHAT_ID` — ID канала или чата, куда бот присылает живые уведомления об ошибках.

## Основные возможности (v7.0)

* **Карточки и тесты на нижней клавиатуре**: управление прямо под большим пальцем без прокрутки чата.
* **Умный поиск с защитой от опечаток**: находит термины от 3 букв даже с ошибками в написании (в боте и в аналитике).
* **Telegram Mini App**: личная аналитика ученика и кабинет учителя открываются прямо внутри Telegram.
* **Оптимизация под бесплатный Neon**: работа через пулер (`-pooler`), кэш прогресса в оперативной памяти и ночной режим сна базы (Scale-to-Zero).
* **Адаптивный дашборд**: авто-тема под устройство (светлая/тёмная), годовой календарь на ПК и помесячный календарь со стрелочками на смартфонах.
* **Живые логи ошибок**: мгновенная отправка стектрейсов сбоев в Telegram-канал.
